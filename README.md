Новое поколение — сайт (React + Vite + Tailwind)
===============================================

Что внутри:
- Готовый React-компонент (src/App.jsx) с основной страницей.
- Простая конфигурация Vite + Tailwind.
- Папка /lessons с готовыми материалами по уровням (Starter, Communicator, Pro).
- /assets/links.txt — ссылки на рекомендованные изображения и платформы.
- README содержит инструкции по локальному запуску и деплою на Netlify/Vercel.

Как запустить локально:
1. Установите Node.js (рекомендовано v18+).
2. В корне проекта выполните:
   npm install
   npm run dev
3. Откройте http://localhost:5173

Деплой:
- Можно задеплоить на Vercel или Netlify: подключите репозиторий, команда сборки: `npm run build`, публичная папка: `dist`.

Примечания:
- В папке assets/links.txt — ссылки на изображения откуда можно скачать подходящие баннеры.
- Для формы записи: используйте Formspree, Netlify Forms или замените кнопку на ссылкуtel: или mailto: для простоты.
